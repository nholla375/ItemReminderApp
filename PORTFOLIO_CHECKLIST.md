# Portfolio Finishing Checklist

## Before sharing this repository

- [ ] Create a dedicated Firebase demo project and add your local `app/google-services.json` (do not commit it).
- [ ] Confirm sign-up/sign-in works with a fake demo account.
- [ ] Confirm create/edit/delete, favorites, categories, archive, reminder, photo, location, and sharing flows all work.
- [ ] Deploy and verify `firestore.rules` in the demo Firebase project.
- [ ] Run `./gradlew test` and, with an emulator/device connected, `./gradlew connectedAndroidTest`.
- [ ] Remove any fake data that contains real names, emails, or exact home/school locations.

## Media to add

- [ ] Record a 15–25 second vertical or device-framed demo.
- [ ] Convert the short clip to `docs/demo/item-reminder-demo.gif` and uncomment the GIF line in the main README.
- [ ] Add screenshots named `home.png`, `add-item.png`, `item-details.png`, and `reminder.png` under `docs/screenshots/`.
- [ ] Uncomment the screenshot table in the main README.

## GitHub presentation

- [ ] Add repository description: `Android item organizer with Firebase sharing, reminders, photos, and optional location context.`
- [ ] Add topics: `android`, `java`, `firebase`, `firestore`, `mobile-app`, `notifications`.
- [ ] Make the repository public when ready for applications.
- [ ] Pin the repository on your GitHub profile if it is one of your strongest 4–6 projects.
- [ ] Keep the first README screen visually strong: title, one-sentence description, demo GIF, then technical highlights.
